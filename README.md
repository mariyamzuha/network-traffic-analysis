# Network Traffic Analysis with Wireshark and tcpdump

Hands-on packet analysis exercises completed in Centri's Introduction to Network Analysis course. Each folder documents what the task was, the filters and commands I used, what the evidence showed, and what I learned.

## Contents

| Folder | What it covers |
|---|---|
| `01-wireshark-challenges` | Wireshark basics and two packet capture challenges (protocols, ICMP, DNS, HTTP, FTP) |
| `02-tcpdump-challenges` | tcpdump on Kali Linux: reading PCAP files, BPF filters, two challenges, and a live browser capture |
| `03-wireshark-capstone` | Final challenge: investigating a simulated ARP spoofing / man-in-the-middle incident |

## Tools

Wireshark, tcpdump, Kali Linux (VirtualBox), Linux command line (grep, cut, head, wc)

## Notes

- The packet capture files (PCAPs) belong to the course, so they are not included here. Written analysis are.
- The write-ups focus on method (filters, commands, reasoning) rather than listing final answers.
- All incidents are simulated lab scenarios.
